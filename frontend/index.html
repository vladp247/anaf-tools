⚡ Download automatically
Pulls files directly from data.gov.ro's public API — no manual browsing. Corporate networks can block this; the manual steps below always work as a fallback.
Financial statement years to fetch:
Or manually — 1. ONRC registry files
Go to data.gov.ro/organization/onrc and open the newest "Firme" dataset (currently firme-08-07-2026 — a new dated snapshot is published periodically, so pick whichever is newest). Download only these 4 files into data/: OD_FIRME.CSV, OD_STARE_FIRMA.CSV, OD_REPREZENTANTI_LEGALI.CSV, OD_REPREZENTANTI_IF.CSV — skip OD_CAEN_AUTORIZAT.CSV and OD_SUCURSALE_ALTE_STATE_MEMBRE.CSV, they're not used. File names are matched case-insensitively.
Or manually — 2. ANAF financial statements (CAEN)
Go to data.gov.ro/dataset/situatii_financiare_2025 and download WEB_UU_AN2025.txt, WEB_BL_BS_SL_AN2025.txt and WEB_IR_AN2025.txt into data/. Swap the 2025 in the URL for any other year (e.g. situatii_financiare_2024) to get that year's files with the same 3 names, just a different year — grab as many years as you want sector history/CAGR for. This step can be finished later from the 🏭 CAEN Analytics tab, which shows per-year coverage and lets you re-index anytime.
